A Mac app for code review

Don’t read the diff. Fathom it.

Fathom reads a pull request as a short paper you referee: how the system behaved before and after, the idea it rests on, what it trades, what could go wrong, and what is still open. One sentence and one figure at a time.

01Premise

Agents write the lines. You own the shape.

When an agent writes the code and a bot checks that it does what it says, reading a diff line by line is no longer the reviewer’s job. The job is judgement.

What was wrong before, and how does the system behave now? What idea does the change rest on, what does it give up, and what could go wrong once it ships? A diff answers none of these directly: it is ordered by file rather than by thought, and gives every line the same weight.

Fathom reorders the change into the shape you would draw on a whiteboard for a colleague, draws it, and sets out what a referee would weigh. Whether to ship it stays your call.1

1Every figure here is Fathom reading one of the author’s own pull requests, walkai #46, unedited.

02Method

How a reading is made

Fathom fetches the pull request and its diff through your GitHub CLI, labels every hunk, and asks Claude, through your own Claude Code, for three things at once: an outline of the change, its story, and a referee’s reading. The story and the referee get read-only access to a shallow checkout of the pull request, so the figures name real types and functions, and the referee can check who calls what before it names a risk. It is told never to invent problems or give generic advice. Everything streams onto the page as it is written, and is kept on your Mac.

03Anatomy

Seven pages, the same every time

A reading opens on an abstract: the change’s vital signs, and the whole pull request in three sentences, Problem, Move and Price. Then six pages, each one sentence and one figure, so you always know where to look.

01

Behaviour

One journey through the system, before and after, as a diff: steps added, gone and changed, and where it broke.

02

Design

Where each part runs and what crosses between them, as a blueprint. Then Box 1, the engineering idea it rests on.

03

Trade-offs

Each decision as a ruled table: the options scored on what separates them, and why this one won.

04

Risk

A one-way or two-way door, and each hazard by likelihood and impact, with its trigger and what guards it.

05

Questions

What the diff leaves open. Settle it, have Fathom look into it, or put it to the author as a comment.

06

Evidence

The passages to read if you read nothing else, with notes in the margin beside the lines.

04Review

When you want the lines, they make sense

When a reading sends you to the code, Changes has the whole diff regrouped into chapters by purpose, each marked read, skim or skip, with a short note above every change. What people and review bots have already said on GitHub sits on the lines it is about. Click a line number to comment, reply in a thread, or suggest a change, and send it all as one review, under your own name.

05Appearance

On paper by day, on water by night

Fathom reads as well at noon as at midnight. The light appearance is warm paper and ink rather than white, with the colours that mark what is new, broken and changed deepened to read on paper, and code set in printed inks. The dark one is deep water. It follows your Mac, or you can choose one in Settings.

30s

From a pull request link to its figures. The referee’s pages follow within the minute.

0s

To open it again. Readings are kept on your Mac.

0keys

No account or server. It runs on your GitHub CLI and Claude plan.

06Principle

Fathom never tells you whether to ship. It shows you what you would be shipping.

So there are no verdicts, no generic advice and no robot approvals. A risk is named only when the diff shows it, with its trigger and what guards it; a reason the pull request does not state is marked inferred; and every figure links back to the lines it was drawn from.

07Install

Free, open source, yours in a minute

  1. Download Fathom, drag it into Applications and open it. It is signed and notarized by Apple.
  2. Install the GitHub CLI, then press Sign In to GitHub in Fathom. It shows a one-time code and finishes by itself.
    brew install gh
  3. Install Claude Code and sign in once. Readings use your Claude plan.
    curl -fsSL https://claude.ai/install.sh | bash
  4. Pick a repository, then a pull request. Or paste a link.
