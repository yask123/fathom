The line

One request. One line. The diff painted on it.

Every part of the system is a rail, grouped by where it runs. Time runs left to right. The request is a single line that crosses from rail to rail, and its colour says what the pull request did to that step.

untouched

The line as it already was. Context for everything else.

new

A step that didn't exist before this change.

changed

Same step, done differently. What it used to do is struck through.

gone

A dashed ghost where a step was removed.

where it broke

The step that went wrong before, with what went wrong.

Forks

Every design decision, as a fork in the road.

The branch the change took, the roads it passed up, and why in one line. No verdict, no list of risks, no advice: the judgement is yours.

The code

Then the diff, in the order it makes sense.

The line carries on into the code: solid green beside what's new, dashed rose beside what's gone. Chapters sort the change into what to read, skim and skip.

drawn, not laid out

Lines are drawn with Core Text, two dozen at a time. A 14,000-point diff scrolls at 7,000 points a second without a late frame.

an editor's hands

Drag to select, double-click a word, triple-click a line, ⌘C the code as written. Click a line number to comment.

review from here

Threads from GitHub sit on their lines. Your comments, replies and verdict post as you.

Under the hood

Your tools. Nothing else.

  • no accountIt runs on the gh and claude you already have. No server, no API key, no sign-up.
  • ~8 secondsFirst words in about two, the whole trace in about eight (Claude Sonnet, a 400-line change). A pull request you've opened before opens at once.
  • what leavesThe diff goes to Claude through Claude Code on your plan; GitHub is reached through your own login. No analytics.
  • openMIT. Native SwiftUI, built with swiftc straight from Sources/. Read it →

Install

On your Mac in a minute.

Download for Mac
  1. Install and open Tracer. Signed and notarized. macOS 26 or later, Apple silicon or Intel.
  2. It checks its two tools and walks you through what's missing: brew install gh, and Claude Code.
  3. Paste a pull request link, or pick one from your inbox. Bookmark tracer:// to jump in from GitHub.
